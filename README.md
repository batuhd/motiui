# MotiUI - Anadolu'nun Dijital Kodları

<img width="1902" height="1034" alt="motiui" src="https://github.com/user-attachments/assets/876a55fb-31ea-4440-b134-e50dd2e61494" />

Anadolu'nun binlerce yıllık geometrik mirasını modern web teknolojileriyle (React, TypeScript, Tailwind CSS v4) buluşturan interaktif bir motif kütüphanesi.

## 🌟 Özellikler

- **Vektörel Varyasyonlar:** SVG path manipülasyonu ile motiflerin geometrik varyasyonları.
- **Akıcı UI:** Framer Motion ile güçlendirilmiş "smooth" geçişler ve snap-scroll carousel.
- **Dark Mode:** Göz yormayan, sistem duyarlı karanlık mod.
- **Responsive:** Mobilden masaüstüne kusursuz deneyim.

## 🛠️ Teknolojiler

- React 19
- TypeScript
- Tailwind CSS v4
- Framer Motion
- Vite
